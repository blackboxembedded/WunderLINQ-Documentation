Introduction

TireLINQ Bluetooth tire sensors fit onto the tire valve stems and send pressure, temperature, battery voltage, and sensor status to the WunderLINQ app. Add and label each sensor in the app, then choose its readings on the Data screen.

Warning: Always check your tire pressure manually with a tire-pressure gauge before starting every ride. TireLINQ readings do not replace this pre-ride check.

Requirements

  • TireLINQ sensors and compatible tire valve stems with clearance for the installed sensors.
  • A phone running a version of WunderLINQ that includes the TireLINQ sensors integration.
  • Bluetooth enabled and the app's requested Bluetooth or nearby-device permissions granted.

This guide uses the supplied Android screenshots. The sensor names, readings, and highlight color shown are examples.

What's in the box

  • Two TireLINQ Bluetooth tire sensors
  • Two lock nuts (set nuts), one for each sensor
  • One wrench

Install

Work on one wheel at a time so you can identify and label its sensor correctly during pairing.

1. Prepare the valve stem and install the set nut

With the motorcycle parked securely, remove the existing valve cap. Check that the stem and threads are clean and undamaged. Set tire pressure to the motorcycle manufacturer's recommendation before fitting the sensor.

First, thread the set nut onto the valve stem, leaving enough exposed thread to fit the sensor. Leave the set nut loose until the sensor is installed.

2. Check the sensor assembly

Each TireLINQ sensor uses a CR1225 battery. This reference photo shows the battery and sealing ring with the outer cover removed. The sensor must be fully assembled with its cover fitted before use. If the cover has been removed, make sure the seal is seated and the cover is secure.

3. Fit the sensor and tighten the set nut

Screw the assembled sensor onto the valve stem until it seats and seals. Avoid cross-threading or overtightening. Finally, tighten the set nut against the sensor to secure it on the valve stem. Check for air leakage and confirm that the sensor clears the brake, fork, and other nearby parts throughout a full wheel rotation.

Repeat for the other wheel after identifying the first sensor in the app.

Pair a sensor

Open App Settings → Integrations and enable TireLINQ sensors. Then open Hardware settings and scroll to TireLINQ sensors. Sensors are added inside WunderLINQ; the app receives their Bluetooth broadcasts.

1. Open sensor discovery

Tap Add TireLINQ sensor. The count below it shows how many of the four available sensor slots are configured. This screenshot already has one saved sensor; a new setup begins with zero.

Waiting for an advertisement means the app has a saved sensor but has not received a reading from it in the current session.

2. Wake the sensor

Keep the phone near the wheel and leave the discovery panel open. Removing and reinstalling the battery is a good way to wake the sensor. After reinstalling the battery, make sure the sealing ring is seated and refit the cover securely before use.

Moving the wheel or changing tire pressure can also wake the sensor. Detected sensors appear automatically.

3. Select the sensor

Tap the detected sensor row. Each row shows an identifier, pressure, temperature, battery voltage, and signal strength. Identify one wheel at a time if several sensors are nearby.

The discovery list displays pressure in bar and temperature in °C. The saved sensor view uses your app's selected units.

4. Name and save

Enter a descriptive label such as Front tire or Rear tire, then tap Save. You can also keep the suggested name, such as TireLINQ 1.

5. Confirm the saved sensor

The sensor now appears under TireLINQ sensors with its label, identifier, and latest readings. Use the pencil to rename it or the trash icon to remove it. Repeat Add TireLINQ sensor for each additional wheel, up to four sensors.

Sensor assignments are saved in the app. The separate Save to WunderLINQ button applies to WunderLINQ hardware configuration and is not needed to save a TireLINQ sensor.

Usage Notes

Show readings on the Data screen

Return to Data, tap a data cell, and select a pressure, temperature, battery, or status field for the configured sensor. Repeat for the other values you want to see. Sensor labels help distinguish the wheels.

The screenshot shows example readings of 0 psi, 75 °F, 3.30 V, and Start-up. These are demonstration values, not recommended tire pressures. Confirm a plausible pressure reading from each installed sensor before riding.

Understand the readings

  • Pressure: the tire pressure reported by the selected sensor.
  • Temperature: the temperature reported by the sensor.
  • Battery: sensor battery voltage, not the phone or motorcycle battery.
  • Status: the sensor's reported state, such as Start-up, Wake-up, Normal / sleep, Inflation, or Deflation / leakage. Low battery may also appear.

The standard Front pressure and Rear pressure motorcycle fields are separate from TireLINQ fields. Select the fields bearing your TireLINQ sensor's label to view its readings.

Use the pencil in Hardware settings to change a label. Removing a sensor removes its live values from the Data grid until it is added again. Check your cell assignments after changing the configured sensor list.

Compatibility

The app supports up to four configured TireLINQ sensors. TireLINQ reception is independent of the connection to WunderLINQ motorcycle hardware: the supplied screenshots show sensor readings while the main WunderLINQ connection is disconnected.

Confirm that the valve stem is suitable for the sensor and that the installed sensor has adequate clearance. Contact support if you are unsure about your wheel or valve-stem fitment.

Troubleshooting

TireLINQ integration is disabled

Enable TireLINQ sensors under App Settings → Integrations, then return to Hardware settings.

The discovery panel keeps listening

Check Bluetooth and the app's Bluetooth or nearby-device permissions. Bring the phone closer and wake the sensor by removing and reinstalling its battery, then refit the cover securely. Moving the wheel can also wake it. A sensor already saved in the app does not appear again in the add-sensor list; check the configured sensor list first.

Waiting for an advertisement

Keep the app open near the wheel and wake the sensor. The message changes to readings when the app receives a broadcast from that saved sensor.

Values are missing from the Data screen

Check that the integration is enabled and the sensor is configured. Tap a data cell and choose the appropriate TireLINQ field. Motorcycle Front pressure and Rear pressure fields do not display the external sensor readings.

The wrong wheel is shown

Check the sensor identifier and label in Hardware settings. Identify one sensor at a time, then rename it or remove and add it again as needed.

Low battery or an unexpected pressure reading

Check the tire with a separate pressure gauge and inspect the sensor's fit and seal. Replace the sensor's battery when its voltage drops below 2.1 V. Use a CR1225 battery, observing the polarity markings. Make sure the sealing ring is seated and refit the cover securely.
